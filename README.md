# 대출 연체 확률 예측 모델과 승인 기준 (German Credit)

대출 신청자의 연체(bad) 확률을 로지스틱 회귀로 예측하고, 그 확률을 **승인 / 심사역 검토 / 자동 거절** 3단계 기준으로 바꾸는 프로젝트입니다.
IBA(지능형 경영 분석 학회) 5주차 팀 과제(2026.09)에서 팀장으로 진행한 최종 모델을, 누구나 재현할 수 있도록 **공개 데이터(UCI Statlog German Credit)** 로 다시 정리했습니다.

- 포트폴리오: https://skcsug.github.io/
- 데모(대출 심사 시뮬레이터): https://skcsug.github.io/credit-demo/

## 원래 과제에서의 결과

| 항목 | 값 |
|---|---|
| 데이터 | 학회 제공 800명(학습) / 200명(채점, 정답 비공개) |
| 최종 모델 | 로지스틱 회귀, bad 가중치 1.8, 임계값 0.5 (11차 제출) |
| 실제 채점 F1 | **0.6667** (31회 제출 중 최고, 1차 발표 0.6522 대비 +1.45%p) |
| 비교한 모델 | 21종 (선형·트리·부스팅·불균형 특화·보팅·MLP·TabPFN 등) |

로지스틱 회귀를 고른 이유: 성능이 가장 좋았고, 보팅이 로지스틱 회귀의 맞은 판단 5건을 랜덤포레스트 쪽으로 바꾸며 진짜 bad 1명을 놓친다는 것을 제출 결과 비교로 확인했습니다. 계수를 오즈비로 바로 설명할 수 있다는 점도 금융 실무에 맞았습니다.

## 이 저장소에서 재현한 결과 (UCI 공개 데이터 1,000명)

`python train.py` 결과입니다. 데이터가 더 많고 채점 데이터가 달라서 숫자는 원래 과제와 다릅니다.

| 항목 | 값 |
|---|---|
| 5-Fold 교차검증 F1 (분할 3가지 평균) | **0.6146** (0.6099 / 0.6197 / 0.6142) |
| 비용 기준 승인 임계값 | P(bad) < **0.37** |

**승인 기준** — 연체 고객을 승인하는 비용 5, 우량 고객을 거절하는 비용 1(UCI 공식 비용행렬)로 총비용이 가장 작아지는 지점을 승인선으로 잡고, 모델이 bad로 판정하는 0.5 이상은 자동 거절, 그 사이는 심사역이 직접 봅니다.

| 구간 | 기준 | 인원 | 실제 불량률 |
|---|---|---|---|
| 승인 | P(bad) < 0.37 | 486명 | 11.5% |
| 심사역 검토 | 0.37 ≤ P(bad) < 0.50 | 137명 | 25.5% |
| 자동 거절 | P(bad) ≥ 0.50 | 377명 | 55.4% |

## 전처리 (최종 제출 설정)

| 변수 | 처리 | 이유 |
|---|---|---|
| Checking / Saving account | 순서형 + "계좌 없음" 플래그 | 계좌 없음(불량률 11.7%)은 잔고 부족(49.3%)보다 훨씬 안전해 순서에 넣을 수 없음 |
| 월 상환액 | log(대출금액 ÷ 기간) 추가 | 금액과 기간이 강하게 얽혀(Spearman 0.63) 따로 해석하기 어려움 |
| Housing | own / non_own | free와 rent의 불량률 차이가 유의하지 않음(p = 0.64) |
| Purpose | 4그룹(자산 구입 · 생활 소비 · 미래 투자 · 기타) | 희소 범주 과적합 방지 |
| Sex | 제외 | 공정성(신용평가 AI 규제) 검토, 포함해도 F1 변동 없음 |

## 실행

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python train.py        # CV F1, 승인 기준 출력 + model/lr_model.json, model/metrics.json 저장
pytest                 # 데이터 매핑, 전처리, 내보낸 모델 = sklearn 확률 일치 검사
```

`model/lr_model.json`은 계수·스케일러 값을 숫자로만 담은 파일이라, 포트폴리오의 웹 데모가 파이썬 없이 같은 확률을 계산합니다.

## 구조

```
credit/data.py       UCI 원본 → 과제와 같은 10개 칼럼으로 변환
credit/features.py   최종 제출 전처리 + 로지스틱 회귀(bad 가중치 1.8)
credit/export.py     모델을 JSON으로 내보내기, JSON만으로 점수 계산
train.py             교차검증, 비용행렬 승인선, 내보내기
```
